# 🧬 Cancer Oncogenesis Global 2026 - Exploratory Data Analysis

## 📌 Overview

This project performs Exploratory Data Analysis (EDA) on a global cancer dataset integrating:

- Clinical data
- Genomic mutations
- Survival outcomes
- Environmental & lifestyle risk factors

The goal is to identify patterns related to cancer prevalence, survival, mutations, smoking impact, age distribution, and regional cancer burden.

---

# 📂 Dataset Information

The project uses multiple datasets including:

- Clinical Genomic Data
- Driver Mutation Frequencies
- Global Cancer Summary
- Mutational Signatures
- Risk Factors
- Survival Data

### Master Dataset Shape
- **Rows:** 10,000
- **Columns:** 35

# 📊 Key Insights

- BRCA had the highest number of patients
- Most cancer cases occurred between ages 50–70
- Smoking-related cancers showed lower survival rates
- Stage IV cancers had the poorest survival outcomes
- Most patients had 0–2 driver mutations
- Survival depends on multiple interacting factors
